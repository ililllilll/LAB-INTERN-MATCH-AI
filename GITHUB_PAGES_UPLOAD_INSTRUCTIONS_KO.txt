LAB MATCH AI — GitHub Pages 배포 방법

1. 이 ZIP을 완전히 압축 해제합니다.
2. 압축 해제된 폴더 안의 파일과 폴더 전체를 GitHub 저장소 루트에 업로드합니다.
3. 저장소 루트에 index.html, .nojekyll, graduate, intern 폴더가 바로 보여야 합니다.
4. GitHub Settings → Pages에서 main 브랜치 / (root)를 선택합니다.
5. 공개된 URL만 학생들에게 공유합니다.

이 배포본은 정적 HTML/CSS/JavaScript/JSON으로만 작동합니다.
방문자와 배포자 모두 Python 설치나 BAT 실행이 필요하지 않습니다.
